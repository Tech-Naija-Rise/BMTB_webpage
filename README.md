# Thought Book

**Your thoughts are yours. Keep them that way.**

Thought Book is a private, offline-first notes app for Windows 11. It gives you a focused place for personal notes and ideas, with password protection and local encryption.

## Get Thought Book

- **[Download the latest Windows release](https://github.com/Tech-Naija-Rise/BMTB/releases/latest)**
- [Explore the application source code](https://github.com/Tech-Naija-Rise/thought_book)
- [View the website source](https://github.com/Tech-Naija-Rise/BMTB_webpage)

## What it offers

- **Offline-first:** write without relying on an online notes service.
- **Local storage:** your notes are stored on your computer.
- **Password protection and encryption:** designed to add a layer of protection to your private notes.
- **Automatic saving and auto-lock:** useful everyday protections and convenience features.
- **A focused desktop experience:** made for capturing thoughts without unnecessary noise.

## Important before installing

The current release targets **Windows 11**. Please read the [latest release notes](https://github.com/Tech-Naija-Rise/BMTB/releases/latest) before installing.

- There is currently no migration system from older versions. Installing a newer version may overwrite the existing database, and old notes may not be readable. **Back up your notes and keep your old version if you need access to existing data.**
- There is no password recovery system. If you lose your password, encrypted notes may be unrecoverable. Set a password hint and keep your password safe.
