Before you install

The current release is intended for Windows 11. It does not include migration from older versions, and installing it may overwrite an older database. Back up your existing notes and keep your old version if you need them. There is no password recovery: if you lose your password, your encrypted notes may be unrecoverable. Read the release notes before installing.

Good to know

Questions, answered.

Does Thought Book work offline?

Yes. It is designed as an offline-first desktop notes app, and your notes are stored locally. You need an internet connection to visit GitHub and download the installer.

Where are my notes stored?

The app stores notes locally on your computer rather than in an online notes account. Keep your own backups, especially before installing a new version.

Can I recover a forgotten password?

No password recovery system is available in the current release. Keep your password somewhere safe and set a password hint during setup.

Will it preserve notes from an older version?

Do not assume that it will. The current release notes warn that migration is not available and an installation may overwrite the existing database. Back up your data first.

Where can I review the code?

The project source is available on GitHub.
